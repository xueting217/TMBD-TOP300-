# TMBD-TOP300电影榜单数据统计分析

## 项目简介
本项目针对TMBD电影榜单前300部电影的数据集进行多维度统计分析，并通过Matplotlib可视化生成直观的统计图表，涵盖电影年份分布、语言分布、类型分布、评分分布等核心维度，帮助快速洞察TOP300电影的特征规律。

## 功能特性
- 数据加载与预处理：自动处理年份缺失值，支持多类型字段解析
- 多维度可视化：
  - 每年电影数量变化折线图
  - 不同语言电影数量柱状图
  - 不同类型电影数量柱状图
  - 不同评分电影数量占比饼状图
- 数据优化：自动合并评分占比过小的类别，提升图表可读性
- 中文适配：完整支持Matplotlib中文显示

## 数据格式要求
输入数据为CSV文件，需包含以下字段：
| 字段名   | 说明                 | 格式示例                |
|----------|----------------------|-------------------------|
| 电影名   | 电影名称             | 肖申克的救赎            |
| 年份     | 上映年份（可为空）   | 1994                    |
| 上映时间 | 上映时间字符串       | 1994-09-10              |
| 类型     | 电影类型（逗号分隔） | 剧情,犯罪               |
| 时长     | 电影时长             | 142分钟                 |
| 评分     | 电影评分             | 9.7                     |
| 语言     | 电影语言             | 英语                    |

## 使用方法
1. 将电影数据CSV文件放置在`data/movies.csv`路径下
2. 运行主程序：
```python
python TMBD_TOP300.py
```
3. 生成的可视化图表会自动保存为`data/test.png`并弹窗显示

## 核心函数说明
| 函数名                | 功能描述                                   |
|-----------------------|--------------------------------------------|
| `setup_matplotlib`    | 配置Matplotlib中文显示参数                 |
| `load_movie_data`     | 加载CSV格式的电影数据                      |
| `preprocess_year_data`| 填充年份缺失值（使用上映时间前4位）|
| `plot_yearly_movie_count` | 绘制年度电影数量变化折线图             |
| `plot_language_distribution` | 绘制语言分布柱状图                   |
| `count_movie_types`   | 统计多类型电影的类型分布（支持逗号分隔）|
| `plot_type_distribution` | 绘制电影类型分布柱状图                 |
| `merge_small_categories` | 合并占比过小的评分类别                 |
| `plot_score_distribution` | 绘制评分分布饼状图                     |

## 输出示例
程序运行后会生成2×2布局的综合统计图表：
- 左上：每年电影数量变化折线图
- 右上：不同语言电影数量柱状图
- 左下：不同类型电影数量柱状图
- 右下：不同评分电影数量占比饼状图

## tip
评分饼图的小类别合并阈值默认为2%，可通过`merge_small_categories`的`threshold`参数调整
